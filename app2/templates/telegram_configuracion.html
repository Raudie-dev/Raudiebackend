¿Cómo crear un bot de Telegram?
1

Busca a @BotFather en Telegram (el bot oficial para crear otros bots).

2

Envía el comando /newbot y sigue las instrucciones para asignarle un nombre y un usuario.

3

Copia el HTTP API Token que te dará (ej: 123456789:AA...).

4

Pégalo aquí y presiona Guardar y Activar. Registraremos el webhook para recibir los mensajes al instante.

¿Cómo obtienen los agentes su Chat ID?
Cada agente debe buscar tu bot en Telegram e iniciar conversación enviando /start. El bot responderá inmediatamente con su Chat ID para que lo agregues en la pestaña de Agentes.
